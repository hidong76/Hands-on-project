# 꿀조합 기준(연차 1일당 4일)을 사용자가 바꿀 수 없다

**Symptom**: 꿀조합 기준이 연차 1일당 쉬는 일수 4 이상으로 고정되어 있어, 더 엄격하거나 느슨한 기준으로 플랜을 만들 수 없다.

**Observed evidence**: 플랜 탭에는 기준을 바꾸는 입력이 없고 기준값은 계산 규칙에 고정되어 있다([honey-plan 결정](../decisions/honey-plan.md)).

**Suspected cause**: 첫 범위에서 의도적으로 뺐다. 4일 기준이 일반 주말 3일 연휴(3.0)와 꿀조합을 가르는 값이라 우선 고정했다.

**What was tried**: 구현하지 않았다.

**Proposed next step**: `shape-idea`로 기준을 입력으로 받을 때의 범위(예: 3~6)와 입력 검증, 기준을 낮추면 2/5~2/10 같은 3.0짜리가 들어오는 영향, 화면 위치를 정한다. 기준이 바뀌면 "합이 같으면 사용 연차가 적은 쪽" 규칙이 검증되는 사례가 생기는지도 본다.
