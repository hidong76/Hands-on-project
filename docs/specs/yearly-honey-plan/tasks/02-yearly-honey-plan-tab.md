# 02 — 1년 꿀조합 플랜 탭

## Outcome

사용자는 연차 수와 기간을 넣고, 탭으로 "1년 꿀조합 플랜"으로 바꿔 꿀조합들로 짠 1년 플랜과 남는 연차를 본다. 기존 "연휴 조합 추천" 탭의 결과와 안내는 탭이 생겨도 이전과 같다.

- 입력 폼은 두 탭이 공유하고 기본으로 열리는 탭은 "연휴 조합 추천"이다. 제출 버튼 문구는 탭을 따른다.
- 플랜 탭에는 요약(꿀조합 횟수, 연휴 총 일수, 사용 연차, 남는 연차)과 날짜순 꿀조합 목록(시작일~종료일, 일수, 연차 쓰는 날짜, 연차 1일당 쉬는 일수)이 보인다. 넓은 화면은 표, 좁은 화면은 카드다.
- 남는 연차가 있으면 "남은 연차 N일은 자유롭게 사용하세요"가 보이고, 꿀조합이 없으면 "이 기간에는 공휴일 꿀조합이 없습니다"와 남는 연차가 보인다.
- 플랜 탭에도 연차 쓰는 날 칩 강조와 풋노트가 같은 방식으로 보인다.

## Blockers

01 — 강조 칩과 풋노트 규칙을 이 task에서 다시 만들지 않고 01의 결과를 재사용한다. 01이 끝나야 플랜 탭의 표시를 같은 구성으로 붙일 수 있다.
